# 大稿批量修订 · 分包给子代理

适用：三万字以上的存量修订，一章一章自己改会吃光上下文。一个五万字、八章的稿子，全量形态线是三百处编辑，分包是唯一能在一次会话里收口的办法。

前提：**先自己改完一章**。那一章的「原稿 vs 修订稿」就是所有子代理的范本（few-shot），比十条规则描述都管用。

---

## 一、开工前准备

1. 把八章拆成独立文件：`<章号>-原稿.md`、`<章号>-当前.md`；自己改完的那一章另存 `<章号>-原稿.md` ＋ `<章号>-修订.md`（＝范本对照）。
2. 决定「引号内标点」算不算本轮范围，**并且写进 brief**（见下）。
3. 按章分任务：一章一个子代理；最短的一两章可以两章并一个。

## 二、brief 必须写死的六件

1. **范本路径**：`<章号>-原稿.md` 与 `<章号>-修订.md`，附一句「看同一段改前改后，这就是标准」。
2. **判据路径**：系列 skill 的 form-rules（§四·十、§四·十三）。
3. **引号内标点的裁定**——不写死，每个子代理都会在破折号这里停住并回一句「两条判据冲突，请裁定」，交回来的稿子破折号一处没动。二选一写清：
   - 收：只许把引号内的破折号换成句读，字一个不许改；
   - 不收：引号内一律不碰，破折号只清叙述层。
4. **硬约束清单**（一段话，别只给判据文件）：台词（「」内）字词不动、条数/顺序/说话人不变；不新增道具、事件、比喻、心理；补动作只用文本里已有的物件；删赘述只删不承担信息的。
5. **输出规格**：纯正文、每段一行、无空行、无标题行（写明「连 `0N：` 那行也不要」——只写「无标题行」，会有一半子代理把章标记当正文首行留着，合并时变成双份）。写到指定路径。
6. **要求回报**：改了多少处 + 拿不准的地方（说话人归属、被拆乱的句子）。这条能省掉一半复查时间。

## 三、验收矩阵（每章都跑，不看自报）

| 项 | 怎么验 | 不过怎么办 |
|:--|:--|:--|
| 台词 | 章级 `dialogue_diff`（原稿 vs 修订），条数与字句 | 少条＝丢了章末或某段，回去补 |
| 硬线 | 章级 `vices`，①②③⑥⑦⑨ | 交给第二遍手改，不让子代理返工 |
| 破折号 | 处数 ÷ CJK × 千，目标 ≤3 | 子代理多半只清叙述层，剩下的自己补 |
| 句密度 | 叙述句均逗号 ≤2.1、最长 ≤6 | 超长的自己断 |
| 同型连续 | `vices` 的连续段计数 | 用「倒装 → 并段 → ⑨ 回改」三遍压 |
| 人读 | 抽头尾各两段 + 所有补动作的段 | 腔调飘了整章退回自己改 |

## 四、已知翻车点

- **子代理会把叙述拆成一拍一段**：⑥ 清零了，同型连续从 39 涨到 50、段均轮次掉到 1.19。这是断段的副作用，不是它的错；回压方法见 SKILL.md §三。
- **并段之后 ⑨ 回涨**：并进同一段的第二处台词还带着冒号。统一把段内第一句之后的「：「」换成「，」，一次收掉。
- **会顺手删掉语气提示**：例如把「「行了吗？」他的声音从旁边过来，问得不重。」改成「他的声音从旁边过来：「行了吗？」」，丢了「问得不重」。属于允许的删赘述，但要在交付账里说明，别当没发生。
- **说话人归属拿不准时会硬判**：原稿本身没写归属的句子（两人交替的短问答），子代理会按上下文挑一个。让它把这类句子列进回报，自己对着上一句问、下一句答核一遍。
- **自报数字不可信**：它们报的「全零」通常是它自己那一版文件的统计。合并回主稿之后再跑一次全篇 `vices`，差别常出在合并处（章首章尾的空行、标记行）。

## 五、合并回主稿

1. 每章去掉标题行后按 `0N：标题` 重新拼，统一 `re.sub(r"\n{2,}", "\n", body)` 压平空行。
2. 拼完立刻跑全篇 `vices` ＋ `dialogue_diff`（对最初的原稿）：合并最容易在章界引入 ⑥（标记行前后）和重复句。另 grep 一遍 `^0[1-8]：`——命中行的长度明显超过标题本身（后面还接着正文）就是章标记被并段粘掉了，先拆回来再做别的统计，否则整章的「章数」都对不上。
3. 全篇同型连续、段均轮次只在合并后才准——章内数字漂亮不代表整篇漂亮。
